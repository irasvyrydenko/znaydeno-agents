# UI: чат + «мозок» системи

Зліва чат, як система виглядає для людини. Справа схема архітектури (Client → Agents → MCP Server → Data),
яка оживає під час роботи: агент «думає» (крутиться кільце, поки йде виклик LLM), по стрілках біжать
повідомлення (запит, виклик інструмента, результат, handoff, hint після відмови, відповідь),
інструменти й CSV-файли підсвічуються, коли їх читають або в них пишуть.
Рожевий стікер показує повний вміст останнього повідомлення, консоль праворуч — ті самі рядки, що й у терміналі.

## Запуск

```
ollama serve                      # якщо ще не запущена
.venv/bin/python ui/server.py     # відкрити http://127.0.0.1:8000
```

## Як це влаштовано

- `server.py` (Starlette, вже є серед залежностей fastmcp) запускає справжній `orchestrator.run_system`
  в окремому потоці й стрімить події в браузер як NDJSON.
- Код агентів не змінено: сервер ззовні обгортає виклик LLM (`base.chat`), MCP-клієнт (`Client.call_tool`),
  запис трейсу (`base.record`) і `run_matcher` / `run_verifier` в оркестраторі.
- `index.html` — один файл без бібліотек: SVG-схема й черга анімацій, щоб швидкі події (виклик інструмента
  триває мілісекунди) було видно оком.
- Запити справжні: збіги пишуться в `data/processed/matches.csv`. Кнопка «Очистити matches.csv» повертає файл
  до заголовка.
